# WIAHost UI research

## Objetivo

Definir una interfaz profesional para WIAHost inspirada en patrones de productos PMS/CRM potentes del mercado, sin copiar pantallas concretas.

La direccion visual es un "hospitality command center": mucha informacion operativa, jerarquia clara, navegacion preparada para equipos y una sensacion de herramienta premium.

## Referencias revisadas

- Hostaway: channel manager, multi-calendar, unified inbox, tareas, statements, reporting y conexiones OTA como ejes de escala.
- Guesty: unified inbox con estados, filtros por urgencia/check-in y multi-calendar como centro de control.
- Lodgify: all-in-one con channel manager, website/direct booking, PMS, pagos, app movil, automatizacion, smart locks y owner statements.

## Patrones que adoptamos

- Dashboard como cockpit, no como coleccion de tarjetas sueltas.
- Multi-calendario visible en primera pantalla para evitar dobles reservas y ver bloqueos.
- Inbox con SLA y prioridad para responder antes de perder conversiones o reviews.
- Salud de canales con sincronizacion, revenue y alertas por OTA.
- Cola prioritaria con "siguiente mejor accion" para operaciones.
- Automatizaciones visibles para check-in, smart lock, checkout y limpieza.
- Sidebar oscuro y contenido claro para separar navegacion de area de trabajo.
- Metricas ejecutivas arriba: reservas, RevPAR, SLA y riesgo operativo.

## Decisiones visuales

- Paleta premium calida: crema operativo, sidebar negro/chocolate y acento lima.
- Cards con radio amplio, bordes suaves y densidad intermedia.
- Dashboard mas denso que landing: debe parecer herramienta de trabajo real.
- Landing con mockup de producto, no hero generico SaaS.
- Mobile mantiene navegacion y contenido legible, priorizando CTA y cockpit resumen.
