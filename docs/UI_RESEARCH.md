# WIAHost UI research

## Objetivo

Definir una interfaz profesional para WIAHost inspirada en los patrones de productos PMS/CRM potentes del mercado, sin copiar pantallas concretas. La dirección es un "hospitality command center": mucha información operativa, clara prioridad visual y navegación preparada para equipos.

## Referencias revisadas

- Hostaway: channel manager, multi-calendar, unified inbox, tareas, statements, reporting y conexiones OTA como ejes de escala.
- Guesty: unified inbox con estados, filtros por urgencia/check-in y multi-calendar como centro de control.
- Lodgify: all-in-one con channel manager, website/direct booking, PMS, pagos, app móvil, automatización, smart locks y owner statements.

## Patrones que adoptamos

- Dashboard como cockpit, no como colección de tarjetas sueltas.
- Multi-calendario visible en primera pantalla para evitar dobles reservas y ver bloqueos.
- Inbox con SLA y prioridad para responder antes de perder conversiones o reseñas.
- Salud de canales con sincronización, revenue y alertas por OTA.
- Cola prioritaria con "siguiente mejor acción" para operaciones.
- Automatizaciones visibles para check-in, smart lock, checkout y limpieza.
- Sidebar oscuro y contenido claro para separar navegación de área de trabajo.
- Métricas ejecutivas arriba: reservas, RevPAR, SLA y riesgo operativo.

## Decisiones visuales

- Paleta premium cálida: crema operativo + sidebar negro/chocolate + acento lima.
- Cards con radio amplio, bordes suaves y densidad intermedia.
- Dashboard más denso que landing: debe parecer herramienta de trabajo real.
- Landing con mockup de producto, no hero genérico SaaS.
- Mobile mantiene navegación y contenido legible, priorizando CTA y cockpit resumen.
